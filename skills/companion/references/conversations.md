# Bounded conversation previews and complete evidence

`context(section=conversations,limit=25,cursor?)` returns descriptors, not transcript bodies. Follow all section cursors. A missing older promise or cancellation is not evidence that it never existed; use exact original references/native history when relevant.

For each incomplete tracked session call conversation_read with session_id, the exact descriptor revision and offset=next_offset, and follow next_offset until complete. Notice review needs only the newest 24,000 text characters of each session served (complete=true); next_offset points inside that window. Older history stays readable from offset 0 when a relevant earlier plan or promise matters. Pages contain at most12,000 text characters and a bounded serialized payload; long messages retain message_offset/text_chars/truncated. Reading the tail first does not certify the gap: next_offset returns the first missing range when necessary. A changed revision returns current revision/next_offset, preserving only the exact unchanged prefix. You can request a fresh descriptor with session_id alone. Served hash/range metadata is not a copied transcript, semantic review or processing watermark.

Do not approve task-notice relevance from a partial preview. notification_review requires the newest text of each available tracked conversation to have been served, then the model's judgment of intent, actual outcomes, later corrections and cancellation; when it returns reviewed=false it lists the exact conversation_read calls still needed. Complete means evidence served, not that a model understood it or a user received/read a result. The review records each session's newest message. A message newer than that holds preparation/finalization until it is read and the notice reviewed again; only the new text needs reading because unchanged prefixes retain coverage. Unavailable sessions other than a task notice's own linked session do not block. To avoid starvation in a busy conversation, a notice already reviewed as relevant that has been held by new messages or an active conversation for an hour is released to the remaining gates (quiet hours, daily allowance, snooze, topic opt-out and deduplication still apply). Operation receipts retain their precise native lookup contracts for scope-specific verification. Missing/pruned history stays a gap.

Signal intake confirms selected fully read IDs; operation review handles consequential cases, not an all-log traversal. Preserve pending authority and partial selected work when the turn budget ends. Feed does not receive raw conversations. Do not add a polling job or replay unknown writes.
